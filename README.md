STUDENT ATTENDANCE MANAGEMENT SYSTEM
A Java-based Student Attendance Management System connected to a MySQL database using JDBC.
Project Description
This project helps manage student details and record daily attendance in a simple and organized way.
Features
- Add student
- Update student details
- Delete student
- Search student
- Mark students as Present or Absent
- View attendance records
- Store student and attendance data in MySQL
Technologies Used
- Java
- MySQL
- JDBC
- VS Code
- Git & GitHub
Main Files
- "Main.java" - Main application
- "DBConnection.java" - Connects Java with MySQL
- "Student.java" - Student data/model
- "TestConnection.java" - Tests the database connection
- "SRS" - Software Requirements Specification
Database
The project uses MySQL to store:
- Student information
- Attendance records
How to Run
1. Install Java and MySQL.
2. Create the required database and tables in MySQL.
3. Add the MySQL Connector/J JDBC driver.
4. Update the database connection details in "DBConnection.java".
5. Compile and run "Main.java".
Purpose
This project was developed as a practical Java project to learn database connectivity, CRUD operations, and basic application development.
